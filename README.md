# 少女唄日 ホームページ

HTML / CSS のみの静的サイト。ビルド不要。`index.html` をブラウザで開けば確認できる。

## 構成

```
index.html      ページ本体（文章はここを書き換える）
css/style.css   見た目（色は先頭の :root で変更）
images/         写真・ジャケット（top.jpg, profile.jpg, ogp.jpg など）
```
